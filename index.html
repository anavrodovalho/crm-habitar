Link do app da web

  1. Abra script.google.com e entre no projeto ligado à planilha Habitar_Leads.

Senha (TOKEN)

  1. No mesmo projeto, procure no código a linha const TOKEN = '...'.
  2. A senha é o texto entre aspas — copie exatamente como está.

Quer conferir antes? Cole no navegador o link do app seguido de ?token=SUA_SENHA. Se aparecer um texto cheio de chaves com os nomes dos clientes, está tudo certo.
